# FreightShift global-editorial restyle

The user explicitly selected and confirmed the premium global-editorial direction over the former industrial/manifest aesthetic. Use generous breathing room, sophisticated readable typography, quieter blue-grey surfaces, subtle route cues, and refined photography. The palette is blue-led with a deliberate amber business accent; avoid arbitrary orange accents and AI-template heading treatments such as highlighted single words or thick decorative underlines.

**Why:** The previous industrial treatment felt too harsh and generic for the company. The user wants FreightShift to remain recognizably logistics-focused while feeling more unique, globally capable, calm, and premium, and explicitly corrected orange accents because FreightShift's colour is blue. This remains a restyle-only project: do not replace real copy or invent telemetry, labels, partners, reviews, or operational facts. No emojis.

**How to apply:** Prefer editorial hierarchy over dense grids, heavy borders, all-caps mono labels, and warehouse-industrial motifs. Keep headings typographically unified; the user specifically requested different colors for the hero destination names, so use amber for China and light blue for South Africa there without applying random word-highlighting to other headings. Use blue for navigation and shipping information, and the business color #FFBF00 for quote actions and selected highlights. Use dark text on amber backgrounds, and a darker amber for small text on white. Preserve every real CTA label, route, section, contact value, tracking flow, and quote flow. After changes run the FreightShift typecheck/build and inspect previews. Production is Vercel; the user pushes via the Replit Git pane.

The user corrected the business highlight to #FFBF00, replacing the earlier mistaken #89674C. **Why:** The later explicit correction supersedes the earlier value; amber should be used intentionally rather than generic orange decoration.

Homepage conversion rhythm should be restrained: one prominent quote action in the hero, quiet contextual text links through the middle, and one strong closing quote action. Avoid repeated button clusters in successive sections.
